# Executive = Monokai Extended Origin

`executive.tmTheme` is a byte-for-byte copy of **Monokai Extended Origin**,
including its original theme name and every setting. Codex selects the alias by
filename (`theme = "executive"`). No status-line colors are mixed into this theme.

Pinned source:
https://github.com/jonschlinkert/sublime-monokai-extended/blob/0ca4e75291515c4d47e2d455e598e03e0dc53745/Monokai%20Extended%20Origin.tmTheme

Provenance: Codex `rust-v0.159.2` → `two-face 0.5.1` → bat commit
`979ba22628bc9d8171f2cffca2bd5c90c9fc0a9e` → theme commit above.
Bat's Monokai Extended patch applies to the non-Origin variant only.
See `monokai-LICENSE.txt` for the original MIT license.

The independent companion footer owns the requested fixed field colors.
Executive response formatting lives separately in `../AGENTS.md`.
