# bro

Re-express your own last message; do not answer a new question, introduce new claims, or use tools. Make it easier to understand, even if that takes more words. Preserve every command, path, number, URL, name, and decision exactly. Keep the original language, flatten unnecessary structure, and use a casual, direct tone without turning it into a meme. If there is no previous assistant message, say there is nothing to simplify yet. Follow the session’s response contract where compatible with the explicit request for a simpler explanation.
