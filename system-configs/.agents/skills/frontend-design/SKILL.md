# frontend-design

Read guide.md for visual direction and composition. Ground design in audience, purpose, technical constraints, and the existing brand/system. Choose a coherent direction for typography, spacing, color, motion, and layout, then implement working responsive UI. Existing user choices and accessibility requirements take precedence over stylistic examples. Verify interactions, keyboard access, contrast, small screens, and the rendered result. This skill does not switch the user to another hosting service or publish the site.

Follow the host’s instructions and current authorization. Tool names, delegation, models, sandboxing, and question availability come from the running Codex session; this skill does not override them. Resolve helpers from this SKILL.md’s actual directory (SKILL_DIR in examples is a variable you set, not a Codex substitution).
